# Arsip LKS Web Technologies

Kumpulan soal dan bahan latihan Lomba Kompetensi Siswa (LKS) bidang Web Technologies untuk dipelajari dan digunakan berlatih.

## Daftar arsip

Arsip dikelompokkan berdasarkan **tahun** (4 digit angka), lalu **jenjang** (`kabupaten`, `provinsi`, `nasional`, atau `wordskills`) dan **lokasi**. Aturan penamaan lengkap ada di [panduan kontribusi](CONTRIBUTION.md#struktur-folder).

## Cara menggunakan arsip

1. Pilih arsip melalui tautan lokasi pada tabel di atas, lalu unduh berkas sumber yang diperlukan.
2. Baca berkas PDF dengan pembaca PDF, atau ekstrak berkas ZIP dan RAR dengan aplikasi yang mendukung format tersebut.
